# Only Bubatz — Shop-Vorschau

**▶ Direkt ansehen: https://celuanw-cmyk.github.io/onlybubatz-preview/**

Klickbare Vorschau des neuen Shopify-Themes „Session 2026" für den Headshop **Only Bubatz**.

- Startseite mit Produktvideo (Volcano Classic, Mighty+, Granny Grinder)
- Produkt-, Kategorie-, Warenkorb- und Suchseite
- „Bubatz Session" mit Bewerbungsformular und „Über uns" mit Partnern
- 18+-Altersprüfung, Warenkorb-Drawer, Quick-Add

Alles läuft mit **Testdaten** aus dem echten Sortiment (Preise, Produktnamen, Kategorien).
Keine echten Bestellungen, keine Live-Daten.

Der komplette Theme-Quellcode liegt unter https://github.com/celuanw-cmyk/onlybubatz-theme
